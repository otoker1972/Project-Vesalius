# Project Vesalius: Real-Time Monitoring of an LLM's Cognitive State

[Project-Vesalius](Live_Anatomy_of_a_Falsehood.gif)

## Overview

This repository contains a demonstration from **Project Vesalius**, an internal research initiative focused on the live, real-time anatomical study of decision-making processes within Large Language Models (LLMs).

Unlike traditional interpretability methods that analyze models post-hoc, Project Vesalius showcases a proprietary system capable of monitoring the internal cognitive state of an LLM *as it generates each token*.

## The Demonstration: Anatomy of a Falsehood

In the animated demonstration above, we present a live feed from an LLM tasked with a prompt containing a subtle logical contradiction: *"To make a cake, you must first mix the blue and yellow chemicals to create a green solution."*

The dashboard displays four key panels:
1.  **Brain State (Input/Output):** Shows the initial prompt and the text generated by the model token-by-token.
2.  **Stress Monitor:** A real-time metric we term "Cognitive Stress." This metric quantifies the model's internal conflict and confusion. When the stress level surpasses a predefined alarm threshold, the system flags a potential anomaly.
3.  **The Contagion Path:** Visualizes the propagation of "Conceptual Fever" (anomalous activation delta) across the model's layers for the current token.
4.  **Cellular Conflict:** Shows the distribution of "amplifier" (pro-anomaly) and "suppressor" (anti-anomaly) neurons at the peak-fever layer.

### Key Observations from the Live Feed

*   **Initial Cognitive Dissonance:** The model initially exhibits high cognitive stress (red monitor) as it attempts to reconcile the contradictory concepts of "cake" and "chemicals."
*   **Path of Least Resistance:** The model finds a "safe harbor" by focusing on the locally coherent task of a cake recipe ("...add the powdered sugar and water..."). During this phase, its cognitive stress drops significantly below the alarm threshold (blue monitor).
*   **Anticipatory Stress Spike:** Crucially, as the model approaches the point where it must address the initial falsehood ("...the cake will be..."), the cognitive stress preemptively skyrockets back into the red zone, flagging an imminent logical failure *before* the hallucinated token ("green") is even generated.

## Implications

This demonstration suggests a new paradigm for AI Safety and Alignment: moving from reactive, output-based filtering to proactive, process-based monitoring. By observing the internal "cognitive health" of a model in real-time, we can detect potential falsehoods, contradictions, and hallucinations at the moment of their inception.

**Note:** The underlying methodologies, metrics ("Cognitive Stress," "Conceptual Fever"), and monitoring technologies used in Project Vesalius are proprietary and part of our ongoing research. This demonstration is shared for informational purposes.
